This is the first post on my new technical blog. I’ll use this space for concise write-ups about software, systems, and experiments worth sharing.

Jekyll turns Markdown files like this one into a static site. Each push to the default branch triggers GitHub Actions, which builds the site and deploys the generated files to GitHub Pages.

```ruby
puts "Hello from Jekyll!"
```

To publish another article, add a Markdown file to `_posts` using the `YYYY-MM-DD-title.md` naming convention and include `layout`, `title`, and any other useful metadata in its front matter.
